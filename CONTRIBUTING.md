# Contributing

Open an issue describing the behavior or submit a focused pull request. Keep project source under `code/` and write new documentation and code comments in English.

Run the checks listed in README.md before submitting changes. Preserve the updater's knowledge boundary, integration choices, collision handling, and fail-closed Git protections. Include a regression test for changes that affect those guarantees.

Use synthetic fixtures for tests. Do not commit personal project knowledge, transcripts, local configuration, credentials, bytecode, or generated target installations.
